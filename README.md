# Already Dead — top-down prototype

Unity **6000.6.2f1**, URP 2D, новый Input System.

Открой `Assets/Scenes/SampleScene.unity` и нажми **Play**. Если ввод не работает, щёлкни по окну **Game**.

Локальная Windows-сборка: `Builds/AlreadyDead/AlreadyDead.exe`. Папку сборки нужно сохранять целиком; она исключена из Git. Для повторной сборки можно вызвать `AlreadyDead.Editor.PrototypeSceneBuilder.BuildWindowsPlayer` через Unity `-executeMethod`.

| Управление | Действие |
| --- | --- |
| WASD | Движение в мировых направлениях, независимо от прицела |
| Мышь | Свободный прицел-крестик и поворот передней части персонажа |
| ЛКМ | Без оружия: удары кулаками; с пистолетом: выстрел; с копьём: укол; с камнем: удар перед собой |
| ПКМ | Над оружием или камнем: подобрать или сразу заменить предмет в руках; прежний останется рядом. Без цели: пистолет и камень бросаются сразу, копьё — после удержания и отпускания ПКМ |
| R | Перезапустить тестовую сцену |
| Esc | Освободить / вернуть игровой курсор |

Камера плавно смещается к курсору, максимум на 2,6 м от персонажа. Без оружия персонаж чередует левый и правый удары; кулак имеет физическую область попадания и лёгкий отклик камеры. Пистолет имеет случайный разброс ±4°, визуальную отдачу, вспышку и тряску камеры. Пули проверяют весь пройденный за физический шаг отрезок; стены перекрывают и выстрел, и подбор. Брошенный пистолет использует 2D-физику без гравитации, вращается, отскакивает от препятствий и затормаживается. Копьё бьёт перед персонажем, летит прямо при броске, останавливается у стены или после заданной дальности и снова доступно для подбора. Чем дольше удерживать ПКМ (до 1,25 с), тем выше скорость и дальность броска.

Короткое ТЗ для художника: `Docs/PIXEL_ART_ASSETS_RU.md`.

Сцена оформлена как песчаная арена в духе пустынной саванны: 20×20-пиксельные тайлы земли, подбираемые камни, сухие кусты и травяные пучки. Камни не имеют обводки выбора; ударяют перед персонажем и бросаются одним нажатием ПКМ. Каменные преграды сохранили прежние коллайдеры. Врагов, здоровья и перезарядки пока нет.

Все параметры находятся в `Assets/AlreadyDead/PrototypeTuning.asset`: скорость, радиус подбора, камера, тряска, темп стрельбы, разброс, отдача, укол и заряд броска копья. Физические материалы — в `Assets/AlreadyDead/Art`. Направление вперёд у визуальной части персонажа — локальная ось **+X**.

Меню **Already Dead → Rebuild prototype scene** пересоздаёт сцену из примитивов (ручные правки сцены заменяются, параметры сохраняются). **Window → General → Test Runner → PlayMode** запускает проверки ввода, движения, столкновений, камеры, подбора, броска и стрельбы.
