# Набор для здания и парковки

Откройте `Assets/Scenes/BuildingParkingScene.unity`. В сцене сохранена ваша расстановка здания и парковки, добавлены персонаж и оружие. Ночной свет URP 2D действует также на персонажа и оружие.

- Откройте **Window > 2D > Tile Palette** и выберите **Building and Parking** из папки `Palette/`. Предметы разнесены на шесть клеток, поэтому крупные изображения не перекрывают друг друга.
- Рисуйте на нужном Tilemap внутри **EDITABLE TILEMAPS**: пол, разметка или стены. У слоя стен есть 2D-коллизия.
- Перетаскивайте мебель, машины и светильники из `Prefabs/`. Весь набор нарисован в ортографии сверху. Для больницы есть `ReceptionDesk`, `IVStand`, `HospitalBedCream`, `HospitalBedTeal`, `ScatteredPapers`, `MedicalWasteBin`; обычная `TrashBin` тоже показана сверху. У `Streetlamp` и `CeilingLamp` настроен свет URP 2D.
- Пиксельные изображения лежат в `Art/`: фильтрация Point, 32 пикселя на единицу мира.
- Группа **PALETTE SHOWCASE** находится за кадром камеры и показывает примеры отдельных объектов.

Пункт меню **Already Dead > Refresh top-down building palette and lighting** обновляет арты, префабы, палетку и освещение персонажа с оружием, сохраняя расстановку сцены. Пункт **Already Dead > Create building and parking kit** пересоздаёт сцену и заменяет расставленные вручную объекты; используйте его только для сброса планировки.
